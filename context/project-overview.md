# Project overview

- **Client:** Shehadey Foods (parent of Producers Dairy). Plants: Producers Dairy (Fresno), Berryfield, Umpqua (Roseburg OR), Model (NV), Mid Valley (Turlock CA). All Pacific Time.
- **Goal:** one EDI platform (Orderful) across all plants before an ERP replacement (~2028).
- **Replacing:** Aptean EDI/VAN (month-to-month). Shut-off estimate for ERMS plants: Jan/Feb 2027 (sales estimate). Overlap cost is a known sensitivity.
- **Roles:** Orderful = EDI platform, partner connectivity. Concurrent = Tray integration, hosted SFTP, project lead (PM: Mark, architect: John). Shehadey = specs, files, BizLink, ERMS.
- **Phase 1:** four ERMS plants — 35 partners / 39 connections (client inventory, Jan–Aug 2026 traffic).
- **Phase 2:** Mid Valley (AX 2009 + Gentran), ~10 partners. Start ~April 2027 (estimate).
- **Total:** ~45 partners; ~6-month rollout (kickoff estimate).
- **Pilot partner:** Costco.
