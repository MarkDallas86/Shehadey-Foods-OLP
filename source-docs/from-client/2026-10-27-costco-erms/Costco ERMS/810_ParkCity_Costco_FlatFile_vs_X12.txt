================================================================================
🎯 BIG04 (PO reference) construction formula — confirmed, reusable
================================================================================
Confirmed across two independent real Park City/Costco orders: BIG04 is not an
arbitrary reference number -- it's constructed from the store number and delivery
date:

  BIG04 = [5-digit zero-padded store number] + [delivery date, MMDD] + [constant "000"]

  This order (Store 141, delivery 10/17): 00141 + 1017 + 000 = 001411017000  ✅ exact match
  Second confirmed order (Store 741, delivery 10/15): 00741 + 1015 + 000 = 007411015000

Important distinction -- two different flat-file formats are involved, don't
conflate them:
- This 810's OWN flat file (Part 1 above, the ERMS format, HDR Field 6) already
  carries the full PO reference and matches BIG04 exactly, every time -- confirmed,
  no issue here.
- The SEPARATE 850 purchase order flat file (Park City Group's PRODUCERS_ORDERS
  fixed-width format, a different system entirely) has its OWN "PO Number" field
  (e.g. "196548" in a real example) -- this is Park City Group's internal batch
  reference and does NOT appear anywhere in the real 810. If searching for an
  order using Costco's actual PO reference, use the BIG04 formula above, not that
  850 file's PO Number field.
